# 🐍 Python — Estudos Organizados

Repositório criado para registrar e organizar minha jornada de estudos em **Python** e **Programação Orientada a Objetos (POO)**.

Aqui estão reunidos exercícios, desafios, anotações e experimentos desenvolvidos durante o aprendizado, organizados de acordo com os principais conceitos praticados.

## 📚 Estrutura

### Python

* `python_VS/Exercicios/02_Listas` — listas e operações com listas
* `python_VS/Exercicios/03_Lacos_For_While` — `for`, `while` e `range`
* `python_VS/Exercicios/04_Dicionarios` — dicionários e tratamento de exceções relacionado
* `python_VS/Exercicios/05_Tuplas` — tuplas, ordenação e `lambda`
* `python_VS/Exercicios/06_Funcoes` — funções, parâmetros, retorno, `*args`, validações e pequenos sistemas

### Programação Orientada a Objetos

* `Poo_Python/Exercicios_` — exercícios organizados pelo conceito principal de POO praticado
* `Poo_Python/Desafios_` — desafios com o tema principal indicado no nome
* `Poo_Python/Rich_Lib` — estudos e experimentos com a biblioteca Rich

## 🎯 Organização

Os nomes dos exercícios foram escolhidos de acordo com o **conceito principal praticado** em cada um.

Quando um exercício possui vários arquivos dependentes entre si, eles permanecem juntos para evitar problemas com imports e preservar a estrutura utilizada durante os estudos.

O objetivo desta organização é facilitar a **revisão, consulta e evolução do aprendizado**.

## 📝 Critério

O código e a lógica dos exercícios foram preservados.

A principal mudança realizada nesta versão foi a **organização dos arquivos e a utilização de nomes mais descritivos**, tornando o conteúdo mais fácil de localizar e revisar posteriormente.

## 🎓 Referências e fontes de estudo

Grande parte dos exercícios e conceitos presentes neste repositório foi desenvolvida durante meus estudos com o curso de **Python 3 do Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O curso foi uma das principais referências utilizadas durante meus estudos de Python, especialmente na construção da base da linguagem e na prática através de exercícios.

Este repositório possui **finalidade educacional** e representa meu processo de aprendizado, incluindo exercícios, adaptações, experimentos e práticas desenvolvidas ao longo dos estudos.
